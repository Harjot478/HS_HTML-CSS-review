About

I'm Harjot Singh — a student at Thomas A. Edison High School who enjoys creative coding using CodeSkulptor and EarSketch. I focus on animation and audio projects and enjoy documenting my process in a simple portfolio.

My Growth as a Programmer

When I started learning to code, I was nervous about whether I could actually create something cool. Over time, I realized that programming is like problem solving. Every project teaches me something new about how to think through challenges and break them down into smaller pieces. I've learned that making mistakes is part of the process and actually helps me learn better. Working with different tools like CodeSkulptor, EarSketch, and HTML/CSS has shown me how many different ways there are to be creative with code. I'm excited to keep learning and building more projects that combine art and technology.

Projects

Holidays (draw) Animation Project

Type: Animation • Tools: CodeSkulptor

A winter holiday scene where snowflakes fall continuously from the sky while ornaments change colors on the tree.

What I Learned: I learned how to use loops to create continuous animations and how to update colors in real time. This project taught me how important timing is when you want to make something feel smooth and natural. I also learned that testing your code over and over helps you catch bugs early.

Holidays Drawing Project

Type: Portfolio / Tech Manual • Tools: CodeSkulptor

In this assignment I was tasked with creating a snowman and a Christmas tree — a practice in shapes and layering.

What I Learned: This project helped me understand how to break down complex drawings into simple shapes. I learned that by combining circles, rectangles, and lines in the right way, you can create anything you imagine. It also taught me about organization in code and how to arrange my shapes in the right order so they layer correctly.

Holiday Remix Challenge

Type: Sound • Tools: EarSketch

Created a holiday-themed sound using EarSketch, focusing on rhythm and layering to evoke a festive mood.

What I Learned: Working with sound taught me a different way to think about code and creativity. I learned how layering different tracks together creates something much more interesting than any single track alone. I also discovered that audio programming has a lot in common with visual programming, and the same logic and problem solving skills apply to both.
